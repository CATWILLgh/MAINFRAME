# Remove MAINFRAME from the selected environment

Execute this objective only for the product and exact removal scope agreed in
the supplied local brief or current conversation. If that scope is missing or
ambiguous, change nothing and direct the operator to [brief.md](brief.md) in
uninstall mode. Do not start a second goal or invent approval.

Consult current official configuration and reload documentation. Apply
[the model-led ownership inspection](support/legacy-audit.md) to each candidate,
rechecking the agreed inventory against actual files and active references.
Do not run a discovery/cleanup script, bulk uninstaller, deletion loop, or
pattern-based rewrite. Read each affected file and use precise native edits.

Back up affected non-secret user-visible files and MAINFRAME-owned registrations
privately. Detach approved registrations before their targets. In mixed files,
remove only proven MAINFRAME-owned sections; preserve user rules and changes.
Preserve ambiguous files, shared credentials and helpers, external scanners,
other adapters, source and archive checkouts, backups, ticket history, and
historical telemetry data unless exact removal was separately agreed. Stopping
a service requires specific scope and authority, not a matching name alone.

Track the agreed finite removal list in a local copy of the same simple
`source`, `purpose`, `done` row format used by [the progress example](../examples/progress.json).
Use actual removal candidates instead of the installation catalog. Set a row
true only after its agreed action and applicable checks; preserve the same
copy for resumption. Do not treat an unresolved ownership conflict as deletion.

Verify preserved configuration parses and confirmed owned registrations are
removed. Check remaining references before removing shared owned files.
Continue independent authorized actions if one item is blocked. Defer required
reloads until all other work is complete, then provide exact continuation
instructions with the brief, checklist, and backup paths. Verify actual loaded
state after reload; do not silently restart other tasks or claim completion
before required checks pass. Report removed and retained items, evidence,
backups, and any remaining limits without credential values.
