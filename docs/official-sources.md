# Find the current official contract

This is a navigation aid for the installing agent, not a capability matrix or
cached specification. Start with the publisher of the actual product and
surface, then follow its documentation index to each layer's owning page.

Examples of official entry points checked during hub authoring:

- [OpenAI product documentation](https://learn.chatgpt.com/docs)
- [Claude Code documentation](https://code.claude.com/docs/en/overview)

Other environments must use their own publisher's official documentation.
A link being listed here does not prove that any feature is supported.

Before installation writes, consult the current owning pages for:

- global instruction loading, scope, recipients, and precedence;
- skill discovery, metadata, supporting resources, and invocation;
- commands and the actual goal lifecycle;
- hooks, events, payloads, output contracts, timeouts, and activation;
- subagent availability, delegation, tool restrictions, model settings;
- configuration ownership, reload, and installed-surface differences;
- model prompting guidance relevant to semantic adaptation.

Confirm the active version and surface locally. Record source links in the
final operator report, not in a permanent telemetry or evidence registry. An
unavailable source or unresolved contract remains an explicit gap.
