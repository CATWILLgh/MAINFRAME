# Проверка исходников хуков

Проверено локально 2026-09-05. Это проверка исходников и сохранённого протокола,
не доказательство подключения к конкретной среде.

## Что проверено

[Набор тестов](../scripts/test_hook_sources.py) выполняется на временных файлах
и репозиториях. Опасные команды передаются как текст и не исполняются.

| Область | Наблюдаемая проверка |
| --- | --- |
| Пути и полномочия | Опасные корни отличаются от узкого удаления; текст команды в printf не считается удалением; обычные локальные операции Git не требуют роли главного агента. |
| Секреты | Проверяется индекс Git, а не рабочая копия; синтетический токен не попадает в ответ; непосредственное чтение отделяется от передачи потребителю. |
| Состояние | Одновременная выдача уведомления атомарна; задачи изолированы; снимки приватны и потребляются один раз. |
| Маркеры | Находка появляется после изменения, повторное событие молчит, другая сессия её не наследует, исправление снимает блокировку; повторный Stop не зацикливает ответ. |
| Комментарии | Строковые значения и допустимый docstring не принимаются за временный комментарий; адресное замечание не повторяется на том же событии. |
| Размер и shell | Неизменённый большой файл не вызывает замечание; shell-подсказка не повторяется и учитывает явный параметр замены. |
| Сканеры | Отсутствие инструмента, ошибка, таймаут и неправильный формат ответа не считаются чистым результатом. |
| Semgrep | Ошибка выдаёт ограниченное уведомление; успешное восстановление молчит; неоднозначное изменение не приписывается конкретной строке. |

19 автоматических тестов прошли. Дополнительно локально выполнены реальные
Ruff, Oxlint и Semgrep на безопасных и заведомо рискованных текстовых примерах:
рискованные примеры обнаружены, безопасные прошли. Тексты примеров не исполнялись.
Это узкие проверки интеграции с установленными версиями, не полный аудит правил
сканеров и не результат CI с реальными сканерами.

## Исправлено по воспроизводимым тестам

- Пустой ответ и неверная структура JSON больше не означают отсутствие находок
  в обвязках Ruff, Oxlint и Semgrep.
- Адресное замечание о временном комментарии учитывает уже выданную находку.

## Принятая граница и оставшиеся ограничения

Блокировки по маркерам и временным комментариям сохраняются по решению
оператора, без механизма исключений. Разрешения отдельных находок, файлов и
каталогов не планируются. Детектор не доказывает семантическую незавершённость:
намеренно добавленный распознаваемый комментарий в кодовой фикстуре тоже может
блокировать завершение. Отсутствие наблюдавшихся жалоб не доказывает отсутствие
ложных срабатываний. Строковые значения и неизменённые старые маркеры остаются
за пределами соответствующих проверок по их исходному контракту.

Доставка событий, корректность полей конкретной среды, таймаут самого хука,
ограничения прав и запись тикета из другого проекта проверяются при установке.
Наличие этих исходников и зелёных тестов не доказывает эти свойства. Атрибуция
через Git HEAD остаётся приближением; точная привязка требует подходящих
событий и снимков одного вызова, как описано в [руководстве](../goals/support/hooks/README.md).
