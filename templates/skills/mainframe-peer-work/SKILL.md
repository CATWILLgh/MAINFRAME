# Work with an external peer

Use an already available authorized product. First consult its current official
documentation for invocation, authentication, permissions, session continuation,
output, and completion signaling. Do not guess flags, depend on a MAINFRAME
launcher, or inspect backing credentials.

Give the peer the bounded result, relevant source evidence, allowed files and
actions, and verification requirements. Resolve `{{SUBAGENT_ROLE}}`,
`{{TOOL_SCOPE}}`, and `{{MODEL_CHOICE}}` using the peer's actual supported
capabilities and operator preferences. A review assignment remains read-only.

Resume the exact peer session for corrections to the same result. Start a new
session for a different result or after acceptance. Separate concurrent writers
by file ownership or an authorized isolated checkout; never overwrite another
agent's work. Prefer documented completion signaling to repeated polling.

Inspect the actual output, changes, and checks before accepting the result.
Treat peer conclusions as claims to verify. If no appropriate peer is available,
continue directly when that meets the task; state the limitation when independent
review was required. Do not install, subscribe, or broaden access implicitly.
