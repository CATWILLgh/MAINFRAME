# Проверка проектного скилла MAINFRAME

## Суть
Понять, помогает ли проектный скилл агенту соблюдать долгосрочные правила и договорённости. В проверенных рабочих копиях корневые инструкции ссылаются на локальные скиллы, каталоги которых исключены из Git. Следующая проверка должна показать, применяет ли агент эти правила в обычной работе.

## Ожидаемый результат
На одной реальной задаче в свежем чате проверить, нашёл ли агент скилл и применил ли конкретную договорённость без отдельной подсказки. По результату решить, стоит ли исправить подключение, оставить короткий скилл для деталей или отказаться от него. Правила, которые должны действовать в каждом клоне, должны быть доступны через отслеживаемый `AGENTS.md`.

## Ограничения
Проектный скилл хранит устойчивые правила и договорённости без истории задач и копий существующей документации. Сначала проверить один проект. Решение об изменении или удалении скилла пока открыто.
