# Operate

Use for dashboards, admin tools, editors, workflows, account areas, and other task-completion surfaces.

- Optimize for clear next actions, scan speed, predictable placement, and recoverable mistakes.
- Keep important state visible: selection, filters, pending work, validation, permissions, and save status.
- Prefer compact but breathable density. Align repeated values and use tabular numerals for comparable numbers.
- Preserve context across dialogs, drawers, pagination, and navigation where the product contract permits it.
- Destructive actions need clear scope, consequence, confirmation proportional to risk, and visible outcome.
- Empty and error states should explain what happened and the useful next action, not merely name the state.

Avoid marketing-sized whitespace, decorative motion, hidden controls, and clever navigation that slows repeated work.
