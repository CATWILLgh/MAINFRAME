# Component map

Choose from what is installed first. Use current CLI search and docs when the nearest component is absent.

| Need | Typical primitive |
|---|---|
| Action | Button with a semantic variant |
| Text or structured input | Input, Textarea, Select, Combobox, Checkbox, RadioGroup, Switch, Slider, InputOTP |
| Small exclusive choice set | ToggleGroup |
| Repeated data | Table, Card, Badge, Avatar |
| Navigation | Sidebar, NavigationMenu, Breadcrumb, Tabs, Pagination |
| Modal decision | Dialog or AlertDialog |
| Side or bottom task panel | Sheet or Drawer |
| Feedback | Alert, Progress, Skeleton, Spinner, project toast implementation |
| Searchable command surface | Command, commonly inside Dialog |
| Data visualization | Chart |
| Layout boundary | Card, Separator, ScrollArea, Resizable, Accordion, Collapsible |
| No-result state | Empty |
| Contextual actions | DropdownMenu, ContextMenu, Menubar |
| Supplemental explanation | Tooltip, HoverCard, Popover |

The table is a routing hint, not an API contract. Confirm the installed component and current docs before implementation.
