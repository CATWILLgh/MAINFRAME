# Read

Use for documentation, articles, knowledge bases, reports, policies, and content-heavy product regions.

- Optimize for comprehension, orientation, progress, and return to context.
- Keep line length, type scale, heading hierarchy, lists, tables, code, and links easy to scan.
- Make navigation and current location visible without crowding the text.
- Preserve semantic document structure; visual size must match heading meaning.
- Support narrow screens, zoom, text reflow, keyboard navigation, copy, search, and anchored links.
- Separate primary content from metadata, actions, related material, and warnings through hierarchy rather than boxes everywhere.

Avoid app-dashboard density, excessive cards, low-contrast prose, sticky furniture that consumes the viewport, and animation during reading.
