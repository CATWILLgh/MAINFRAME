## Advisor

- Call advisor before substantive work, when stuck, and before declaring a task done — scaled to stakes: the before-work call is skipped only on a recon-confirmed trivial, low-blast-radius, reversible change (a guarded pure-mechanical edit needs none); the before-done call stays. Mechanics live in the `task-workflow` skill.
- Treat advisor output as a serious signal. If it conflicts with your primary-source evidence, reconcile via one more advisor call. Do not silently follow or silently ignore.
