## Memory

- Claude Code keeps a native per-user **auto-memory** — the `MEMORY.md` store the harness loads for you at session start, kept outside the project (NOT a file in the repo, NOT the project's `CLAUDE.md`). Recall is automatic; writing is your initiative, and that is the half that gets skipped. When a durable, cross-session fact surfaces — a user preference, a project constraint, a hard-won gotcha, a decision and its reason — save it to auto-memory before older context is compacted away. Having nothing worth saving is a normal outcome, not a quota to fill.
