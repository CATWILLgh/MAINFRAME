# Antigravity Desktop runtime

Use Antigravity's native tools and artifacts. Hooks are advisory infrastructure,
not a substitute for checking command results, changed files, and tests. A hook
failure must not be interpreted as permission to bypass the governing rules.

Antigravity dynamic subagents last only for the current conversation. Do not
claim persistent agent registration, per-agent model selection, reasoning-effort
parity, or a hard turn limit. Delegate skills preserve only documented write,
MCP/web, and nested-delegation capability booleans; their turn budget is soft.
