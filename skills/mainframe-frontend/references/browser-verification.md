# Browser verification

Choose rendered evidence for the changed contract. Inspect static appearance in
the real rendered surface; exercise changed interactions as a user would.
Source inspection or a build alone does not establish rendered behavior, and a
screenshot alone does not prove interaction.

Use the receiving project's configured interactive verification route. When no route is established, prefer your product's native interactive browser if it is available and permitted; verify its current capabilities before relying on it.

Reuse an available route that provides the required observation within current
authority. Ask only if missing capabilities require a new installation,
permission, service lifecycle action, or material project configuration choice
not covered by the task. If project configuration changes are in scope, record a
newly established route there; an existing adequate tool needs no setup decision.

A mechanism is adequate when it can observe the changed contract. Require click,
typing, keyboard, viewport, download, or browser-API capabilities only when that
behavior is affected. Inspect console or runtime failures relevant to the result.

Exercise affected states with representative data. Select viewports, keyboard and
focus checks, themes, motion settings, recovery paths, and draft preservation
according to the changed risk. A small text edit needs a rendering check where
wrapping could change; a responsive modal needs viewport, focus, and interaction
coverage. Wait for observable rendering or navigation readiness, not a fixed delay.

Use an authorized local or test contour. Do not spend money, mutate production, alter credentials, or trigger irreversible operations merely for visual proof. Keep simulated data visibly distinct from live runtime evidence.

Capture screenshots when useful for appearance and pair them with interaction
evidence when behavior changed. Report the relevant observations and limitations.
If an essential observation is unavailable, state the exact unverified boundary.
